# 1.1 New project as a page

Goal: New project opens as a `catalogPage` page from every entry, and the
dialog is gone. Branch `slavakoreshkov/hoo-2709-new-project-page`, base
`scope/interface-2`.

## Steps (TDD: the test first in each)

1. `widgets/catalog`: `ShownPage = CatalogPage | "new-project"` in
   `model/telemetry.ts`, `catalog_shown.page: ShownPage`,
   `CatalogVia += "lesson"`. `catalogPage` stores `ShownPage`.
   Test: `catalog-page.test.ts` opens `new-project` and reports it.
2. `widgets/catalog/ui/NewProjectPage.tsx`: `useNewProject(() => catalogPage.closePage("new-project"))`
   plus `<NewProject>`. `catalogSlot` maps `new-project` to the title "New
   project". Test: `catalog-slot.test.tsx`. Update the comments in
   `use-new-project.ts` from dialog to page.
3. `widgets/app-nav/ui/AppNav.tsx`: `NavPage` includes `new-project`. The
   item calls `onOpenPage`, and the modal import goes. Test:
   `AppNav.test.tsx` (marked current, `onOpenPage("new-project")`).
4. `widgets/home`: `PageTile = HomeTile`. `BaseHome`'s tile calls
   `onTile("new-project")`, and the `scratch` prop and the unfold go. Update
   `Home.tsx` and the tests.
5. `views/flow/Flow.tsx`: `openGallery = () => catalogPage.open("new-project",
   "lesson")`. Delete `views/flow/gallery/` (the modal and its two tests).
   `NoFileOpen` takes `onStartProject`, and `components/Editor` passes
   `catalogPage.open("new-project", "editor")`.
6. Routes: `routes/new/` (`/new` → `openPageFromLink("new-project")`),
   `catalog-paths.ts` LINKS gets `/new`, `openPageFromLink` takes
   `ShownPage`, then `yarn generate-fast`.
7. e2e: `new-project.e2e.spec.ts` scopes to the page region (and covers
   `/new`), plus `fixtures.ts` `createProject` / nav helper, `home`,
   `lesson-path` and `workspace-migration`.
8. Gate: `yarn run check`, then the changed e2e specs locally on the stubs.
