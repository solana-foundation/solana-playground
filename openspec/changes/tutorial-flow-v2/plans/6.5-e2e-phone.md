# 6.5 e2e for the flow, phone half (HOO-2510) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hello Anchor from the intro card to the finish card at 390 px, in
CI's e2e job, on the stubbed build server and devnet the desktop half
(HOO-2364, [6.5-e2e-desktop.md](6.5-e2e-desktop.md)) built.

**Architecture:** One new spec, `e2e/tutorial-hello-anchor-phone.e2e.spec.ts`,
on `fakeBuildServer` and `fakeDevnet`. The helpers the desktop spec keeps
private (the lesson's beats, options, act cards, wins) move to
`e2e/hello-anchor.ts`, parameterised by the feed locator, so both specs read
the copy from `src/tutorials/hello-anchor/tutorial.json` the same way. No
app code changes.

**Tech Stack:** Playwright, the e2e fixtures (`e2e/fixtures.ts`), `PHONE`
from `e2e/viewports.ts`.

**Spec:** `openspec/changes/tutorial-flow-v2/specs/tutorial-phone/spec.md`,
`specs/tutorial-conversation/spec.md` ("Reload in step 3").

## Global Constraints

- The phone is `PHONE` (390 x 844), below the frame's 1024 px and the
  768 px tablet line; the tablet band is not walked.
- The chat is the region "Chat", the code the region "Code"; the header's
  switch is "Show the code" / "Show the code, new lines written" on Chat and
  "Back to the chat" on Code.
- A failed build on the phone offers "Explain the error" and no "I'll fix it
  myself"; question cards offer no "Type it myself"; no win card has "Open
  Call".
- The finished header reads "Done · N of N", N the lesson's step count.
- Every test ends with both fakes' `unhandled` empty.

## Review Focus

- The phone draws one Start, in the composer's place (`BaseTutorialComposer`);
  the intro card draws none there (`BaseIntroCard`). The test asserts the
  count, so a second one, or none, fails it.
- Chat and Code stay mounted in one strip that slides; `toBeVisible` passes
  for both whichever shows. The test reads which one is on screen from
  `inert`, set on the one out of view.
- The controls the phone leaves to the desktop are checked while their card
  is live: no "Type it myself" on an open question (with Hint present), no
  "I'll fix it myself" on the failed build, no "Open Call" on a win.
- The reload in step 3 lands on Chat (`useTutorialSpace`'s default), still
  in the phone layout. "Reload in step 3" is a manual scenario; the test
  covers its feed only.
- The Code space shows the step's file after the build (`lib.rs`).
