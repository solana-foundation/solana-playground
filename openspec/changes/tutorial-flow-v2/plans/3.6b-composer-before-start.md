# Composer before Start Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans, inline. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Before Start, a free answer ends by inviting the learner to begin, and a turn that only opens the menu still leaves them a next move.

**Architecture:** #271 already routes a lone start word to step 1, so that part only gains the spec line, the missing test cases and an e2e. The invitation is the model's to write, so it goes in the tutorial's context and in the menu tool's result. The composer's "Ready to start the lesson?" row is the part no model can skip, so it also counts a turn that ran a tool and wrote nothing.

**Tech Stack:** TypeScript, React, vitest, Playwright.

**Spec:** `openspec/changes/tutorial-flow-v2/specs/tutorial-conversation/spec.md`, "One composer; free questions go to the live assistant"; ticket HOO-2571.

## Global Constraints

- Invitation copy: "When you're ready, press Start step 1 or type start."
- A start word is a message that is only `start`, `begin` or `go`, alone or with "please", in any case.
- The phone is untouched: before Start, "Start step 1" takes the composer's place.

## Review Focus

- A model that opens the menu and writes nothing: the composer still suggests starting.
- A tool that ran before the last Start over: it does not count as answered.
- During the lesson the menu tool's result carries no invitation.
- "go ahead" is not a word: it goes to the assistant.
