# 1.1 Interact instruction cards — plan

**Goal:** the #272 instruction card on scope/users-work-2's Interact stage
(HOO-2652), keeping its call path, result, history and two columns.

**Shape:** `Instruction` renders itself as an `Interaction` card (as on
foundation master) with `open`/`onOpenChange`; `InteractBody` owns the set of
open names and the last result's instruction. Mode: inline, TDD.

## Steps

1. **Interaction** (`sidebar/test/Component/Interaction.tsx`): take #272's
   card (head `min-h-12`, `meta` quiet beside the name, body under a
   hairline) plus optional controlled `open` / `onOpenChange`; Accounts and
   Events stay uncontrolled. Test: `meta` renders; controlled `open` shows
   the body; heading click calls `onOpenChange(false)`.
2. **InputLabel**: #272's neutral `mut`/`signer` tags, type in quiet mono
   (`data-slot="input-type"`). Update `InputLabel.test.tsx` to master's.
3. **Instruction** (`Instruction/Instruction.tsx`), tests first in
   `Instruction.test.tsx`:
   - head meta `inputsMeta` ("1 arg · 1 account"; none for no inputs);
   - plain groups "Arguments"/"Accounts" (h4), no folds;
   - row: `Test` (`loadingText="Testing…"`), ghost "Fill with Random",
     ghost "Reset" (only with inputs), held reason:
     wallet → `Add <solNeededOn> SOL to test` → `Fill every field to test`;
   - keep: `onCall`, fieldset lock while testing, restored-values check,
     Fee payer slot above the row;
   - prop `callBlocked` → `solNeededOn?: string`.
4. **InteractBody**, tests first in `InteractBody.test.tsx`:
   - chips and the `Segmented` import go; one `Instruction` per IDL
     instruction, wrapped in `data-instruction=<name>` for scrolling;
   - `open: Set<string>` empty on arrival; toggling per card;
   - `last` keeps `{target, instruction, outcome}`; `BaseCallResult` right
     after that instruction's card;
   - history row: add name to `open`, then `scrollIntoView` on that card
     (after the render, in an effect keyed on a scroll request);
   - `callBlocked` → `solNeededOn`; `Interact.tsx` passes `short?.cluster`.
5. **e2e** — `client-v2-stages`, `client-v2-idl`, `client-v2-sources`: replace
   chip picks with opening the card heading and "Call <name>" with "Test".
6. **Verify:** `yarn run check` in `client-v2/`; the changed e2e specs run in
   CI; screenshots via Playwright (list on arrival, a card with its result,
   the fee hold) on a dev server in slot 6+.
