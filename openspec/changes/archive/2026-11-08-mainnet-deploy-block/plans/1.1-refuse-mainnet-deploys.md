# Refuse mainnet deploys Implementation Plan

> **Superseded in review (HOO-2728).** What shipped differs from Task 1 below: `refuseMainnet` (`check-not-mainnet.ts`) refuses an endpoint that does not answer (`DEPLOY_NETWORK_UNREAD`, 15 s limit) and passes only `UnknownClusterError`; `processDeploy` checks again on its own connection before any send; a tutorial deploy refuses while the name is stale. The archived spec and design are the record; this plan is the starting point only.

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** No program deploy to mainnet-beta from Playground; the Deploy stage points mainnet to "Deploy from your machine".

**Architecture:** One pre-check at the head of the `deploy` command (every caller passes through it) reads the cluster from the endpoint and throws a `TerminalLineError`. The Deploy stage reads `PgConnection.cluster` and swaps its line and pill on mainnet. The warning module becomes the block module.

**Tech Stack:** React 19, vitest + Testing Library, Playwright.

**Spec:** `openspec/changes/archive/2026-11-08-mainnet-deploy-block/specs/` (mainnet-deploy-warning, cli-deploy deltas), ticket HOO-2728.

## Global Constraints

- Stage line, verbatim: `Deploys to mainnet are not available in the beta.`
- Pill, verbatim: `Deploy from your machine`.
- Settings line, verbatim: `Not available for deploys`.
- Terminal line, verbatim: `Deploys to mainnet are not available in the beta. Deploy from your own machine with the Solana CLI or Anchor: Deploy stage › Deploy from your machine.`
- `GuideFrom` = `"mainnet-blocked" | "deploy-stage"`.

## Review Focus

- `PgConnection.cluster` still `null` or naming the previous network when `deploy` runs → the guard reads the endpoint, so it still refuses (unit: cached cluster `devnet`, endpoint mainnet → refused).
- Custom RPC with mainnet genesis → refused (unit: `getCluster` resolves `mainnet-beta` for a custom URL).
- Endpoint unreachable (genesis read throws) → guard passes, nothing refused on a guess (unit).
- A mainnet deploy history from before this change → stage still shows the line and the pill, history stays listed (component test with a mainnet record).
- Program Pal / explorer menu deploys → same command, so covered by the command test; no separate path.
