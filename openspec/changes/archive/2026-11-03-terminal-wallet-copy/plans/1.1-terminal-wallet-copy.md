# 1.1 Terminal lines (Spec 13) and wallet help (Spec 12)

Ticket: HOO-2524 · base `scope/interface-2` · mode: inline.

## Success metric (from the ticket)

Each line appears in the terminal or wallet panel with the spec's copy when
its condition is triggered; screenshots in the PR.

## Design gaps (decided here, sent to the designers' batch)

1. No line for an unknown command with nothing close: "`<typed>` is not a
   command. Type `help` to see commands." (Spec 13's form; Design alignment
   agreed, 3 Nov)
2. No wallet question for a command that takes any wallet: "No wallet is
   connected. Connect the Playground Wallet? [Y/n]".
3. The kept-buffer line's wording is dev's (Spec 13 open question 3): split
   into two sentences at the semicolon.
4. Where the wallet help sits: a help mark beside a Playground wallet's
   name in the panel's title bar, none for an extension wallet.

## Steps

1. **Plain-line error** (`src/utils/terminal/line-error.ts`):
   `TerminalLineError` and `isTerminalLine`. `PgTerm.process` prints its
   message as is. Test first: `terminal-process.test.ts` gets a case that a
   `TerminalLineError` prints without "Process error:".
2. **Suggestion** (`src/utils/terminal/unknown-command.ts`, in-source
   tests): a distance function (optimal string alignment) and
   `unknownCommand(typed, names)` returning the line and the suggestion. Tests: `biuld` -> build,
   `ls` -> shell line, `xyzzy` -> help line, a tie takes the earlier name.
3. **Wire it** in `PgCommandManager.execute`: throw a `TerminalLineError`
   with the line; when there is a suggestion, push it to history through a
   new `PgTerm.offerFromHistory(command)` (shell `history.push`).
4. **Confirm suffix** in `PgTerm.waitForInput`: `[Y/n]`/`[y/N]`/`[y/n]`, no
   "(default: …)" for a confirm; fold case and map `y`/`n` (`confirmReply` in
   `utils/terminal/confirm.ts`, in-source tests). The wiring inside
   `PgTerm.waitForInput` is covered by the manual scenarios.
5. **Wallet question** in `checks.ts`: the two questions, the "no" as a
   `TerminalLineError`. Unit test with a stubbed terminal.
6. **Buffer line** in `commands/deploy/stopped.ts`; update its test.
7. **Wallet help** in `components/Wallet/Wallet.tsx`: `HelpTip` with label
   "About the Playground wallet" when `wallet.isPg`; extend
   `Wallet.test.tsx`.
8. **e2e** `e2e/client-v2-terminal.e2e.spec.ts`: the four scenarios of "An
   unknown command suggests the closest one", titled
   `client-v2-terminal: <scenario>`.
9. Gate: `yarn run check`, plus the new e2e spec; screenshots (before on
   `origin/scope/interface-2`, after on this branch) of the terminal lines,
   the wallet question and the wallet help.
