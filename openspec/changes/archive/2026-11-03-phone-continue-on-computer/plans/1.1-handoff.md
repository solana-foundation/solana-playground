# Continue on a computer: implementation plan

> For agentic workers: run inline with superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** the phone's menu page offers "Continue on a computer", opening a sheet with a link to open on a computer.

**Architecture:** `BaseHandoff` (props only) draws the row and the DS `Drawer`; `Handoff` connects `PgSession`, the router, the clipboard and the events. `BaseAppNav` gains a `handoff` slot drawn only with `phone`; `AppNav` fills it.

**Tech stack:** React 19, Tailwind 4 DS tokens, vaul `Drawer` from `shared/ui`, vitest + testing-library, Playwright.

**Spec:** `../specs/client-v2-handoff/spec.md`, `../design.md`.

## Global constraints

- Copy, verbatim: row and title "Continue on a computer"; "Copy link" / "Copied"; "Share"; "Stay on the phone"; "Sign in with GitHub".
- Signed in line: "Your projects are saved to your account. Open this link on a computer and sign in with GitHub as @<login>: this project is in your list there."
- Signed out line: "This project is saved on this phone only. Sign in with GitHub to keep it in your account, then open this link on a computer and sign in there too."
- Test ids: `handoff-open`, `handoff-link`. Events: `nav_handoff_opened {signedIn: boolean}`, `nav_handoff_link_copied {}`, `nav_handoff_link_shared {}`.

## Review focus

1. Clipboard refused (insecure context, permissions): no "Copied", a toast via `reportButtonFailure`. Test in Task 1.
2. Share cancelled: no event, no toast. Test in Task 1.
3. Signing in while the sheet is open: the sheet turns to the signed-in words. Test in Task 1 (rerender).
4. A long link at 390 px: wraps in the well, the page does not scroll sideways. e2e in Task 2.
5. Frame widths: the row is never in the DOM. Tests in Tasks 1 and 2.
