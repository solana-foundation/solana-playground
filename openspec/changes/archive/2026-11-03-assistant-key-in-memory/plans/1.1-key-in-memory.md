# 1.1 Key in memory only, and Delete my key

Ticket: HOO-2423. Mode: inline.

## Success metric (from the ticket)

After Delete my key, and after a reload, no browser storage (`localStorage`,
`sessionStorage`, IndexedDB) holds the key string, and the assistant needs
the key again before the next turn: checked by the e2e scenarios
"assistant-own-key: A reload asks for the key again" and
"assistant-own-key: Delete my key from Settings".

## Design gaps (decided, sent to the designers' batch)

1. Where the button lives: there is no Program Pal section in Settings yet.
   Decided: a new **Assistant** section after Network, one row "Your model
   key".
2. Confirmation: none, as for the head's item; the key can be typed again.
3. Name: the head's "Forget key" becomes "Delete my key", so one action has
   one name.
4. Reload: the designers' spec 07 keeps the key across a reload; the
   security review (this ticket) overrides it.

## Steps (TDD: each test fails first)

1. `remembered-backend.ts`: in-source tests "never writes the key to
   sessionStorage" and "drops a connection an older build kept"; then make
   `rememberBackend` write only `localStorage` and drop any kept entry;
   replace `rememberedConnection` with `dropKeptKey` (returns whether gone).
2. `use-turn.ts`: mount effect calls `dropKeptKey()` instead of reconnecting
   a kept key; update `use-turn.test.tsx` cases that relied on the reconnect.
3. `store.ts`: comments; store tests that read `rememberedConnection`.
4. Head: rename to Delete my key (`BaseAssistantHead`, `Assistant`), fire
   `assistant_key_deleted`; update tests.
5. Settings: `AssistantKey` row in `SettingsPage.tsx`, section id
   `assistant` in `SECTION_ORDER` after `network`; `settings_key_deleted`;
   test in `BaseSettingsPage`/a new `AssistantKey` test with the memory
   provider.
6. Connect note copy.
7. e2e: rewrite the `assistant-own-key` describe in
   `assistant-reconnect.e2e.spec.ts` for the new scenarios; fix other specs
   that seed `assistant.connection` or click "Forget key".
8. Gate: `yarn run check`, the changed e2e specs, screenshots before/after
   of Settings and the head menu.
