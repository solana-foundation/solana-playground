# Sign in to share Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-out Share as gist shows a "Sign in to share" prompt; signing in turns it into the share dialog with nothing sent.

**Architecture:** `app/ShareGistDialog` switches on `PgSession.get()`: signed out it renders a `ModalFrame` whose submit signs in; signed in, today's share frame. The frame's submit gains an optional icon for the GitHub mark, exported from `widgets/session-footer`.

**Tech Stack:** React 19, Vitest + Testing Library, the overlays widget's `ModalFrame`.

**Spec:** `openspec/changes/share-sign-in-prompt/specs/gist-sharing/spec.md`, `design.md` beside it.

## Global Constraints

- Copy, verbatim: title `Sign in to share`; line `Your project goes to a gist on your GitHub account.`; submit `Sign in with GitHub`; Cancel is the frame's own.
- Frame names (telemetry, kebab-case): `share-gist-sign-in` for the prompt, `share-gist` for sharing (unchanged).
- No new telemetry event; no `catch` left empty; no nested ternaries.

## Review Focus

- A known sign-in failure (popup closed, popup blocked) is shown in the prompt and not reported to Sentry: test asserts the message and no `report: true` log.
- An unknown error from `signIn` is still reported: rethrown into the frame, which shows and reports it.
- A sign-in that finishes elsewhere (account menu, another tab) while the prompt is open moves the dialog to sharing: test sets the session with `PgSession.refreshWith` without pressing.
- Busy state: the submit shows the spinner instead of the mark while the popup runs, and Cancel is disabled.
- Nothing reaches `/api/gists` from opening the prompt or signing in: `fetch` spy asserts no call to it.
