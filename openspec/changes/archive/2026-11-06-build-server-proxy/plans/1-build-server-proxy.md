# Build server proxy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put a same-origin route in front of the Foundation's build server. The route requires GitHub sign-in and writes an audit row per build. The server can require an API key, so the route is the only way in.

**Architecture:** The Vercel function `api/build-server.mjs` takes `/api/build-server/*` through a rewrite. It checks the origin and the session, records the build in Postgres, and forwards to `PG_BUILD_SERVER_URL` with `x-api-key`. The Rust server gets an opt-in axum middleware. The client's "Solana Foundation" option resolves to the route on its own origin.

**Tech Stack:** Node ESM on raw `http` APIs, `node:test`, Postgres via `features/persistence/server.mjs` `query`, dbmate, axum 0.8, vitest, Playwright.

**Spec:** `openspec/changes/build-server-proxy/` (proposal, design, `specs/build-server-access/spec.md`).

## Global Constraints

- Route paths: `POST /build`, `GET /deploy/<uuid>`, `POST /unstable/build`, `GET /unstable/deploy/<uuid>`; others `404`, wrong method `405`.
- Signed-out body exactly `{ "error": "Sign in with GitHub to build.", "reason": "signed-out" }`, status `401`.
- Other site origin `403`; sign-in unconfigured or session unreadable `503`; audit insert failure `503`, no upstream call.
- Server: `PG_API_KEY` env, header `x-api-key`, constant-time compare, `401` on mismatch, share routes untouched, key never printed.
- Route env: `PG_BUILD_SERVER_URL` (default `https://playground-server-dot-analytics-324114.de.r.appspot.com`), `PG_BUILD_SERVER_API_KEY`.
- Body cap 1 MiB (`1024 * 1024`), the server's own `PAYLOAD_LIMIT` default.
- `project.id` and `project.name` capped at 200 characters each.
- `maxDuration` 300 for `api/build-server.mjs`. No other `vercel.json` change except the rewrite.
- Build stage copy: "Sign in with GitHub to build", button "Sign in with GitHub".

## Review Focus

- A request with an `Origin` from another site but a valid cookie → `403`, never forwarded (route test).
- Upstream unreachable or timing out → `502` with a message, audit row completed with status `502` (route test).
- A client that disconnects mid-build → the upstream fetch is aborted, no unhandled rejection (route test with an aborted request).
- `uuid` with path tricks (`../share/x`, `%2e%2e`) → `404` (allowlist test).
- An old profile that stored the Foundation's direct URL as `custom` → still lands on the route (stored-endpoint test).
