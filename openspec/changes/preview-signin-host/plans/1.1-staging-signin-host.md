# Plan 1.1: staging sign-in host for previews

Goal: production never hosts preview sign-in and holds no `AUTH_OAUTH_PROXY_*`;
previews carry only the staging host's values (HOO-2816).

1. Tests first (`node --test`): `oauth-proxy.test.mjs` cases for the host flag
   (host only with `AUTH_OAUTH_PROXY_HOST=true`; production with the secret
   alone, or a preview's settings, installs no proxy; flag without secret is
   reported); `scripts/check-auth-env.test.mjs`; `scripts/env-overlap.test.mjs`.
2. `auth.mjs` + `server-env.mjs`: read the flag, decide the three roles.
3. `scripts/check-auth-env.mjs`, run from `scripts/vercel-build.sh` after
   `check-agent-env.mjs`.
4. `scripts/env-overlap.mjs` for the runbook's preview-vs-production check.
5. Docs: `deploy-client-vercel.md` "Sign-in on previews" and release
   checklist, `production-runbook.md` row, `neon.md`, `.env.example`.
6. Gate: `yarn run check`; CI runs the database-backed proxy cases.
