> **Executed** (inline, 2026-10-20). Where the code differs from this plan,

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home reachable from an open project (the navigation's Home, the
last project's delete, Back to `/`), and going back finds the editor, its
undo history and the console as they were.

**Architecture:** While a project is current, `BaseLayoutShell` keeps
rendering the stage and console into their outlets under Home (the outlets
stay detached), so nothing remounts. `PgView` replays the newest delivered
main-primary setter to a `Primary` that mounts with no call waiting, which
fills the editor after the last-delete unmount. `useStartView` becomes the
page's view state for the whole load, with `showHome(via)` and
`leaveHome(via)`.

**Tech Stack:** React 19, TypeScript, vitest + Testing Library, Playwright.

**Spec:** `openspec/changes/ui-migration/design.md`, "Home from an open
project (5.28)"; `specs/client-v2-layout/spec.md`, "Home is reachable from
an open project", "Home is measured", "The navigation opens the gallery".
Branch stacks on PR #114 (HOO-2063 review fixes); rebase on `new-face`
once it merges.

## Global Constraints

- Telemetry values verbatim: `home_shown {via: "start" | "nav" | "last-deleted" | "back"}`, `home_left {via: "current-project" | "continue" | "open" | "nav"}`.
- The address does not change when Home shows.
- Ids, `aria-label`s and test ids stay (`Home` nav item, `Continue <name>` quick start).
- No empty `catch`; failures through `createLogger(...)` with `report: true`.
- No nested ternaries; state shaped as a type.
- Gate: `yarn run check` and `yarn test-e2e e2e/home.e2e.spec.ts` (plus any other spec this diff edits). Never the full suite.
- Tests: no spread to build new shapes (`client-v2/AGENTS.md`).

## Review Focus

1. A temporary project (share or GitHub route, `PgExplorer.isTemporary`) has no current name: it must never be read as "last deleted". Pinned in Task 3.
2. Another tab deletes the last project (`tab-reload` runs `PgExplorer.init()`, no delete event here): Home must show. Pinned in Task 3 (`onDidInit`).
3. Home → back with the editor inside a detached outlet: Monaco must relayout, not stay 0 px. Pinned by the e2e in Task 5 (the typed text is visible after return).
4. Home while the start is still `pending` or after the watchdog fell back to the work with no project: `showHome("nav")` must not mount the work. Pinned in Task 3.
5. Continue on the phone for the open project must not `switchWorkspace` to itself (re-reads the workspace under a live Monaco). Pinned in Task 4.
