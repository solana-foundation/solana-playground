# Home on start (5.8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A page load on `/` with no project shows Home (question, composer,
tiles, tutorial cards; on a phone, quick starts and Browse) in place of the
work, instead of the gallery modal, and the editor does not mount under it.

**Architecture:** A new widget `widgets/home` holds the views
(`BaseHome`/`Home`, `BasePhoneHome`/`PhoneHome`), its telemetry, and the start
decision (`useStartView`: `pending | home | work`). `LayoutShell` gains an
optional `home` slot: with it, the frame keeps the navigation and puts Home
where the assistant and the work go, the pager shows Home on its work page
with no preview page, the stage and console outlets are not rendered, and the
assistant is a right Sheet at every width. `Flow` replaces the
open-the-gallery-when-empty effect with `useStartView`. `PgView.setMainPrimary`
gets #32's `isSet` guard, because the route's retries pile up while Home
keeps the editor unmounted.

**Tech Stack:** React 19, TypeScript, Tailwind 4 with the design system in
`shared/ui` (installed with `yarn ds-add`), vitest + Testing Library,
Playwright.

**Spec:** `openspec/changes/ui-migration/design.md`, "Home (5.8)";
`openspec/changes/ui-migration/specs/client-v2-layout/spec.md`, requirements
"The navigation opens the gallery", "A start with no project opens on Home",
"Home is measured".

## Global Constraints

- Every command runs from `client-v2/` with Node 22.20
  (`PATH=$HOME/.nvm/versions/node/v22.20.0/bin:$PATH`).
- `shared/ui` is installed, never edited by hand: `yarn ds-add composer action-card`.

  `flow-left-tab-*`, `#root-dir`.
- No empty `catch`: rethrow, log through `createLogger("home:<module>")` with

- Tests do not build new shapes by spreading (client-v2/AGENTS.md).
- Telemetry prefix `home`, registered in `shared/lib/telemetry/prefixes.ts`;
  every event has a doc comment (`app/slice-structure.test.ts`).
- Home in the navigation, while a project is open, opens the gallery as in
  5.2 (HOO-2118 brings it back to Home). Continue on the phone never shows
  in this task; `BasePhoneHome` takes it for HOO-2118.
- The composer only opens the assistant.
- Gate: `yarn run check` plus the touched e2e specs, one at a time,
  `PORT=<slot port> yarn test-e2e e2e/<spec>.e2e.spec.ts`. Never the full

- [ ] **Step 3: Implement the guard**

```ts
  static async setMainPrimary(setEl: SetState<SyncOrAsync<Elementable>>) {
    // An attempt that times out keeps waiting for its answer, so every one
    // made while no main view was mounted (Home keeps it unmounted) is
    // answered at once when one mounts. Only the first may set the view, or
    // each runs the route's setter again.
    let isSet = false;
    await PgCommon.tryUntilSuccess(async () => {
      const eventNames = PgCommon.getStaticStateEventNames(
        PgView.events.MAIN_PRIMARY_STATIC
      );
      const result = await PgCommon.sendAndReceiveCustomEvent(eventNames.get);
      if (result === undefined) throw new Error();

      if (isSet) return;
      isSet = true;
      PgCommon.createAndDispatchCustomEvent(eventNames.set, setEl);
    }, 100);
  }
```

- [ ] **Step 4: Implement `start-view.ts`**

```ts
import { useEffect, useState } from "react";

import { createLogger } from "@/shared/lib/logger";
import { PgExplorer, PgRouter } from "@/utils";
import { homeTelemetry } from "./telemetry";

export type StartView = "pending" | "home" | "work";

const log = createLogger("home:start");

/**
 * Home is for a start on `/` with no project. Any other route opens straight
 * on the work; on `/` the answer waits for the explorer.
 */
export const decideStart = ({
  path,
  workspaces,
}: {
  path: string;
  workspaces: readonly string[] | undefined;
}): StartView => {
  if (path !== "/") return "work";
  if (workspaces === undefined) return "pending";
  return workspaces.length ? "work" : "home";
};

/**
 * Whether the page shows Home, the work, or neither yet. The route
 * initialises the explorer inside the editor's mount, which Home does not
 * have, so on `/` this initialises it first; `PgExplorer.init` runs its calls
 * one after another, so the route's own call later is harmless. Once the
 * work shows it stays for the page load (coming back is HOO-2118).
 */
export const useStartView = (): StartView => {
  const [view, setView] = useState<StartView>(() =>
    decideStart({
      path: PgRouter.location.pathname,
      workspaces: PgExplorer.allWorkspaceNames,
    })
  );

  useEffect(() => {
    if (view !== "pending") return;
    let live = true;
    PgExplorer.init()
      .then(() => {
        if (!live) return;
        setView(
          decideStart({
            path: PgRouter.location.pathname,
            workspaces: PgExplorer.allWorkspaceNames ?? [],
          })
        );
      })
      .catch((e: unknown) => {
        // The work is today's start and still works without Home
        log.error(e, { report: true });
        if (live) setView("work");
      });
    return () => {
      live = false;
    };
  }, [view]);

  useEffect(() => {
    if (view !== "home") return;
    homeTelemetry.track("home_shown", {});
    const toWork = () => {
      if (PgExplorer.allWorkspaceNames?.length) setView("work");
    };
    const subs = [
      // A project made here, or the account's arriving by sync
      PgExplorer.onDidCreateWorkspace(toWork),
      PgExplorer.onDidSwitchWorkspace(toWork),
      PgRouter.onDidChangePath((path) => {
        if (path !== "/") setView("work");
      }),
    ];
    return () => subs.forEach((s) => s.dispose());
  }, [view]);

  return view;
};
```
