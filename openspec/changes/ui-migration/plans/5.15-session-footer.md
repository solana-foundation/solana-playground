# Session footer and account menu (5.15) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the navigation footer's status chips and the floating Feedback button with the prototype's session footer (a cluster row and an account row) and one account menu, opened from the footer and from the rail.

**Architecture:** A new widget `widgets/session-footer` holds pure `Base*` components (no store) and connected wrappers. The wrappers read `PgSession`, the wallet hooks and the cluster status, and they take feedback from `features/feedback`, which keeps its state in `FeedbackHost` and now hands out menu items and the send status in place of its trigger. `views/flow/Flow.tsx` passes the new components into `AppNav`'s existing `footer` and `railFooter` slots and binds ⌘, to the settings toggle.

**Tech Stack:** React 19, TypeScript, Tailwind 4, shadcn/Radix parts from `@/shared/ui` (DropdownMenu, Dialog, Sidebar, Avatar, StatusDot, Spinner), vitest + Testing Library, Playwright.

**Spec:** `openspec/changes/ui-migration/specs/client-v2-layout/spec.md` (requirements "Four columns and no header" and "The session footer and account menu"), `openspec/changes/ui-migration/design.md` ("Session footer and account menu (5.15)"), `openspec/specs/client-v2-feedback/spec.md` ("The account menu offers feedback" and "The form takes a rating, a message and an optional handle").

## Global Constraints

- Run everything from `client-v2/` with Node 22.20 (`export PATH=$HOME/.nvm/versions/node/v22.20.0/bin:$PATH`).
- Layers: `widgets/session-footer` may import `features/*` (public `index.ts` only), `shared/*` and legacy roots; `features/feedback` imports no other feature.
- `shared/ui` is never edited by hand.
- Kept names: rail dot "Cluster: <name>" (", down" appended when down); cluster row "Change cluster, currently <name>" (", down" appended); "Connect wallet"; "Sign in with GitHub"; the `data-settings-trigger` attribute (`SETTINGS_TRIGGER_ATTR`) on everything that toggles the settings.
- The account controls are named `Account: <login or name>` when signed in and `Account, signed out` when not; tests match `/^Account/`.
- Docs opens `https://solana.com/docs` in a new tab with `rel="noopener noreferrer"`.
- Telemetry prefix `session`; events `session_account_menu_opened {from: "footer" | "rail"}` and `session_account_item_picked {item}`, each with a doc comment.
- No empty `catch`; failures that the team must hear of log through `createLogger("session-footer:<module>")` with `report: true`.
- No nested ternaries; in test files no spread to build fixtures (`client-v2/AGENTS.md`).
- No "Proposal" group in the menu.
- Commits use Conventional Commits with the `(client-v2)` scope and no AI attribution.

## Review Focus

1. A signed-in account with `login: null` (name only): the row shows the name, the menu shows no "Open GitHub profile", nothing crashes. Pinned in Task 2 (`accountLines`) and Task 3.
2. Picking "Settings" in the menu while the settings are already open closes them, not close-then-reopen (the item carries `SETTINGS_TRIGGER_ATTR`, so `GearSidebar`'s outside click ignores it). Pinned in Task 3 (attribute present) and Task 7 (e2e).
3. A wallet whose balance has not loaded yet (`null`) shows "…" instead of "0.00 SOL" or "NaN". Pinned in Task 2.
4. A wallet connect or disconnect that rejects (the user dismisses the wallet's prompt) is logged with `report: true` and leaves the menu usable. Pinned in Task 5.
5. On a narrow window (740 px), signing in from the menu in the navigation's Sheet, then closing the Sheet, keeps the sign-in going: the state lives in `PgSession`. Pinned in Task 5 (state read from `PgSession.signInState()`, never local).

```ts
import type { SignInState } from "@/features/auth";
import type { ClusterStatus } from "./use-cluster-status";

/** What a user can pick in the account menu (and the row's Cancel), for telemetry */
export type AccountItem =
  | "sign-in"
  | "cancel-sign-in"
  | "github-profile"
  | "sign-out"
  | "settings"
  | "docs"
  | "cluster-down"
  | "connect-wallet"
  | "wallet"
  | "disconnect-wallet";

export interface AccountUser {
  name: string | null;
  login: string | null;
  image: string | null;
}

export interface AccountWallet {
  /** Base58 */
  address: string;
  /** In SOL; `null` until it has loaded */
  balance: number | null;
}

/** Everything the footer, the rail and the menu draw */
export interface AccountView {
  user: AccountUser | null;
  signIn: SignInState;
  wallet: AccountWallet | null;
  cluster: ClusterStatus;
  /** A feedback send is in flight behind a closed form */
  sending: boolean;
}

export const DOCS_URL = "https://solana.com/docs";

export const githubProfileUrl = (login: string) =>
  `https://github.com/${login}`;

export const shortAddress = (address: string) =>
  `${address.slice(0, 4)}…${address.slice(-4)}`;

export const formatBalance = (balance: number | null) =>
  balance === null ? "…" : `${balance.toFixed(2)} SOL`;

const displayName = (user: AccountUser) => user.login ?? user.name ?? "Account";

/** The account controls' name: the visible text alone would not say what they open */
export const accountLabel = ({ user }: AccountView) =>
  user ? `Account: ${displayName(user)}` : "Account, signed out";

/** The two lines of the account row */
export const accountLines = (view: AccountView) => {
  const primary = view.user ? displayName(view.user) : "Sign in";
  if (view.signIn.status === "pending") {
    return { primary, secondary: { text: "Signing in...", tone: "muted" as const } };
  }
  if (view.signIn.status === "failed") {
    return { primary, secondary: { text: "Couldn't sign in", tone: "error" as const } };
  }
  if (view.wallet) {
    const text = `${shortAddress(view.wallet.address)} · ${formatBalance(view.wallet.balance)}`;
    return { primary, secondary: { text, tone: "muted" as const } };
  }
  return { primary, secondary: null };
};

/** Named, not only coloured, so a screen reader hears a cluster that is down */
export const clusterLabel = (
  cluster: ClusterStatus,
  prefix: "Cluster: " | "Change cluster, currently "
) => `${prefix}${cluster.name}${cluster.down ? ", down" : ""}`;
```

              size="lg"

import { useState } from "react";

import { PgSession } from "@/features/auth";
import { FeedbackMenuItems, useFeedbackSend } from "@/features/feedback";
import { useBalance, useRenderOnChange, useWallet } from "@/hooks";
import { createLogger } from "@/shared/lib/logger";
import { PgCommand, PgCommon, PgWallet } from "@/utils";
import type { SettingsFocus } from "@/views/flow/settings/GearSidebar";
import type { AccountItem, AccountView } from "../model/account";
import { sessionTelemetry } from "../model/telemetry";
import { useClusterStatus } from "../model/use-cluster-status";
import BaseAccountMenu from "./BaseAccountMenu";
import BaseSignOutDialog from "./BaseSignOutDialog";

const log = createLogger("session-footer:account");

interface UseAccountOptions {
  from: "footer" | "rail";
  onToggleSettings: (focus?: SettingsFocus) => void;
}

/**
 * What both account controls show and do. Sign-in progress is read from
 * `PgSession`, never kept here: on a narrow window the footer sits in the
 * navigation's Sheet, which unmounts it on close while the sign-in goes on.
 */
export const useAccount = ({ from, onToggleSettings }: UseAccountOptions) => {
  const cluster = useClusterStatus();
  useRenderOnChange(PgSession.onDidChange);
  const wallet = useWallet();
  const balance = useBalance();
  const { sending, triggerRef } = useFeedbackSend();
  const [confirmingSignOut, setConfirmingSignOut] = useState(false);

  const user = PgSession.get();
  const account: AccountView = {
    user: user && { name: user.name, login: user.login, image: user.image },
    signIn: PgSession.signInState(),
    wallet: wallet
      ? {
          address: wallet.publicKey.toBase58(),
          balance: typeof balance === "number" ? balance : null,
        }
      : null,
    cluster,
    sending,
  };

  const toggleWallet = (item: AccountItem) => {
    // The command toggles: it connects when nothing is, and disconnects the current wallet
    PgCommand.connect.execute().catch((error: unknown) => {
      log.error(error, { report: true, context: { item } });
    });
  };

  const actions: Record<AccountItem, () => void> = {
    "sign-in": () => {
      PgSession.signIn().catch((error: unknown) =>
        // `PgSession.signInState` holds the failure and the row shows it from
        // there; `auth` telemetry already has its reason
        log.info("sign-in failed", { context: { error: String(error) } })
      );
    },
    "cancel-sign-in": () => PgSession.cancelSignIn(),
    // Links: the anchor opens the tab, the pick is only counted
    "github-profile": () => undefined,
    docs: () => undefined,
    "sign-out": () => setConfirmingSignOut(true),
    settings: () => onToggleSettings(),
    "cluster-down": () => onToggleSettings("network"),
    "connect-wallet": () => toggleWallet("connect-wallet"),
    "disconnect-wallet": () => toggleWallet("disconnect-wallet"),
    wallet: () => {
      PgWallet.show = true;
    },
  };

  const pick = (item: AccountItem) => {
    sessionTelemetry.track("session_account_item_picked", { item });
    actions[item]();
  };

  const onMenuOpenChange = (open: boolean) => {
    if (open) sessionTelemetry.track("session_account_menu_opened", { from });
  };

  const settingsShortcut = PgCommon.getOS() === "MacOS" ? "⌘," : "Ctrl+,";

  const menu = (
    <BaseAccountMenu
      account={account}
      feedback={<FeedbackMenuItems />}
      side={from === "footer" ? "top" : "right"}
      settingsShortcut={settingsShortcut}
      onPick={pick}
    />
  );

  const dialog = (
    <BaseSignOutDialog
      open={confirmingSignOut}
      onOpenChange={setConfirmingSignOut}
      onConfirm={() => {
        setConfirmingSignOut(false);
        PgSession.signOut().catch((error: unknown) => {
          log.error(error, { report: true, context: { item: "sign-out" } });
        });
      }}
    />
  );

  return { account, pick, menu, dialog, onMenuOpenChange, accountRef: triggerRef };
};
