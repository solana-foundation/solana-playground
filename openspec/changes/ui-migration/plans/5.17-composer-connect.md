# 5.17 Composer and Connect a model: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The assistant's head, composer (context chips, model, effort, Send turning to Stop) and the Connect a model dialog are built from the design system, naming the real default model.

**Architecture:** A new widget slice `src/widgets/assistant/` owns the head, the composer, the model and effort menus and the dialog, as `Base*` + connected pairs. The turn logic (provider, send, stop, prompt requests) moves out of the legacy `Chat.tsx` into the slice's `model/use-turn.ts`; `Chat.tsx` keeps only the thread. The store, the providers and the `Connect` form stay in `views/sidebar/assistant/`.

**Tech Stack:** React 19, Tailwind 4, the design system's `composer`, `modal`, `dropdown-menu` (installed with `yarn ds-add`), vitest + Testing Library, Playwright.

**Spec:** `openspec/changes/ui-migration/design.md`, "The composer and Connect a model (5.17)"; `openspec/changes/ui-migration/specs/client-v2-assistant/spec.md`.

## Global Constraints

- Branch off `origin/new-face`; the PR targets `new-face`.
- Node `^22.20.0`; every command runs from `client-v2/`.
- `shared/ui` is installed, never edited by hand: a change to `composer` is made in `design-system/src/components/ui/composer.tsx`, then `yarn ds-add composer`.
- Ids, `aria-label`s and test ids survive: "Message the assistant", "Conversation", "Send", "Stop", "Collapse assistant", "Expand assistant", the form's "Start" and "Connect", `assistant-api-key`, `assistant-base-url`, `assistant-model`.
- No empty `catch`; failures log through `createLogger("assistant:<module>")`, with `report: true` where the team must hear of it.
- No nested ternaries; state as a type, not as flags; ids from `shared/lib/ids`.
- Tests build no shape by spreading another (`client-v2/AGENTS.md`).
- Do not edit files of the open elements PRs (#68, #72) until they merge. `Connect.tsx` is edited only in Task 9, after #72 and #71 merge.
- The default backend's display name is "GLM 5.3 Flash" for `z-ai/glm-5.3-flash:US`; an unknown id is shown as it is. "Opus 5.5" is never shown for a backend that is not connected to it.
- Effort is shown only for a backend with `modelSettings`.
- Clear conversation is shown disabled (HOO-1741).

## Review Focus

1. A prompt placed in the composer by "Fix with assistant" (not typed): Send must be enabled. Pinned in Task 1 and Task 6.
2. The `/api/agent` probe failing (network error, 500, a body without `model`): the composer still renders, the model reads "Connect a model", the failure is logged. Pinned in Task 2.
3. Changing model or effort mid-thread on the same backend: the thread stays on screen and the next turn sees it. Pinned in Task 3.
4. Stop pressed while an approval card is pending: the pending approval is denied and Send comes back. Pinned in Task 6.
5. Send pressed twice fast, or Enter held: one turn only. Pinned in Task 6.
