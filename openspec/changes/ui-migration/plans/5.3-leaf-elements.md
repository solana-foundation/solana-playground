# Leaf elements (5.3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tag, Callout, Badge, Checkbox and Label, Collapsible, Kbd, Empty,
StatusDot, Avatar, Logo and Switch come from the design system across
client-v2, and the legacy `Tag`, `Text`, `Checkbox`, `Foldable` and
`ProgressBar` are deleted (HOO-2058).

**Architecture:** Install the design system's parts into `shared/ui` with
`yarn ds-add`, registering the stock ones first. Swap call sites file by file;
each swap deletes a styled-component. Call sites in files the other element
PRs change (#68 HOO-2061, #69 HOO-2055, #72 HOO-2060, HOO-2059) wait for
those to merge and are swapped after a rebase (Phase B); the legacy
components are deleted last.

**Tech Stack:** React 19, Tailwind 4, shadcn on Radix (`radix-ui`),
`lucide-react`, vitest + Testing Library, Playwright.

**Spec:** `openspec/changes/ui-migration/design.md`, "Leaf elements (5.3)";
`openspec/changes/ui-migration/specs/client-v2-elements/spec.md`.

## Global Constraints

- `shared/ui` is installed, never edited by hand: change the design system,
  then `yarn ds-add <name>`.
- Ids, `aria-label`s and the texts the e2e reads do not change.
- No empty `catch`; failures log through `createLogger(...)` with
  `report: true`.
- No nested ternaries; a two-plus-way choice is an `if` chain or a `Record`.
- Do not patch a styled-component with a Tailwind utility on the same
  property: drop the styled rule or the styled wrapper.
- Tests build fixtures without spreads (`client-v2/AGENTS.md`).
- e2e titles are `client-v2-elements: <scenario name>`.
- Commits: Conventional Commits, `(client-v2)` scope; no AI attribution.
- Every command runs from `client-v2/` with Node 22.20
  (`export PATH=~/.nvm/versions/node/v22.20.0/bin:$PATH`).

## Review Focus

1. A controlled fold (`isOpen` + `setIsOpen`, Interact's Result) must stay
   controlled: the parent's state opens it after a fetch. Pinned in Task 6.
2. A fold that starts open (`isOpen` without `setIsOpen`) must re-open when
   `isOpen` turns true later, as the legacy `useEffect` did. Pinned in Task 6.
3. A checkbox's `onChange(ev)` callers read `ev.target.checked`; Radix calls
   `onCheckedChange(checked)` with `boolean | "indeterminate"`. Every caller is
   rewritten, none adapted with a fake event. Pinned in Task 5.
4. A callout's children that are `<p>` blocks keep their spacing (the legacy
   `& > p:not(:first-child) { margin-top: 1rem }`). Pinned in Task 3.
5. An unknown tutorial level still renders (as `error`), and an unknown
   framework name does not throw. Pinned in Task 4.

```tsx
import { ChevronRightIcon } from "lucide-react"
import { cn } from "cn"

/* The fold's mark: points right when closed, down when open. Put it inside
   a CollapsibleTrigger. */
function CollapsibleChevron({ className, ...props }: React.ComponentProps<typeof ChevronRightIcon>) {
  return (
    <ChevronRightIcon
      data-slot="collapsible-chevron"
      aria-hidden="true"
      className={cn("size-4 shrink-0 transition-transform duration-200 [[data-state=open]>&]:rotate-90 motion-reduce:transition-none", className)}
      {...props}
    />
  )
}
```
