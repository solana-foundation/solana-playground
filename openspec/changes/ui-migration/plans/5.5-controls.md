# Controls from the design system (5.5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The stepper, the choices of a few, the selects and the plain fields in `client-v2` come from the design system, and react-select goes (HOO-2060).

**Architecture:** Each control is installed into `shared/ui` with `yarn ds-add` and used in place at its call sites; no call site moves. The stepper keeps its file and props so HOO-2055 (which moves it into the stage column) moves an import only. Tests are vitest + Testing Library for each call site, and Playwright for the four `client-v2-controls` scenarios.

**Tech Stack:** React 19, Radix (`radix-ui`), Tailwind 4, styled-components (legacy, shrinking), vitest, Playwright.

**Spec:** `openspec/changes/ui-migration/design.md`, section "Controls (5.5)"; `openspec/changes/ui-migration/specs/client-v2-controls/spec.md`.

## Global Constraints

- Node `^22.20.0` (`export PATH=~/.nvm/versions/node/v22.20.0/bin:$PATH`); all commands from `client-v2/`.
- `shared/ui` is installed, never edited by hand: `yarn ds-add <name>`; a change goes to `design-system/` and is reinstalled.
- Ids, `aria-label`s and test ids survive: `flow-stage-tab-*`, `flow-stage-panel-*`, `aria-label="Development loop"`, `aria-label="Network"`, `aria-label="Framework"`, `id="assistant-model"`, `id="assistant-base-url"`, `id="assistant-api-key"`, `[data-settings-trigger]`.
- No empty `catch`; a refused or failed action logs through `createLogger(...)` with `report: true`.
- No nested ternaries. Tests: no spread to build a new shape (`client-v2/AGENTS.md`); write the explicit copy.
- Commits: Conventional Commits, scope `(client-v2)`; no AI attribution.
- `toggle-group` and `input-group` are not installed: no call site uses them yet (no multi-toggle, no field with an addon). The first screen that needs one installs it. `design.md` says so (Task 1, step 6).

## Review Focus

1. **A setting whose value matches no option** (a custom RPC URL in Endpoint). Expect the trigger to show "Custom", as react-select's `options.at(-1)` fallback did; pinned in Task 3.
2. **Radix forbids `""` as a `SelectItem` value.** The "Custom" option had `value: ""`; it gets the sentinel `CUSTOM_VALUE`, and picking it opens the custom modal without calling `setValue`; pinned in Task 3.
3. **Arrow keys in the network group select as they go** today; Radix ToggleGroup only moves focus. Selection must still follow focus; pinned in Task 5.
4. **A select inside the assistant Sheet** must open above it (both are `z-50`; the select's portal mounts later); the existing e2e "a select inside the assistant Sheet" stays green; checked in Task 8.
5. **The stepper at narrow widths** keeps initials below 80rem, and the full name stays in `aria-label`; pinned in Task 2.

```tsx
import { useSyncExternalStore } from "react";
import type { FC } from "react";

import { Stepper as DsStepper, StepperItem, StepperList } from "@/shared/ui/stepper";
import type { StepperStatus } from "@/shared/ui/stepper";

/** `upcoming` and `active` are both "nothing to report": the thumb marks the current stage */
const DS_STATUS: Record<StageStatus, StepperStatus> = {
  upcoming: "idle", active: "idle", done: "done", running: "running", failed: "failed",
};

/**
 * Below this width the four labels collapse to their initials, which is
 * what stops the stepper crowding its neighbours on a narrow window. The full
 * name stays in each tab's `aria-label`.
 */
const STEPPER_COMPACT_QUERY = "(max-width: 80rem)";

const subscribeCompact = (onChange: () => void) => {
  const list = window.matchMedia(STEPPER_COMPACT_QUERY);
  list.addEventListener("change", onChange);
  return () => list.removeEventListener("change", onChange);
};
const isCompact = () => window.matchMedia(STEPPER_COMPACT_QUERY).matches;

const Stepper: FC<StepperProps> = ({ state, onSelect, target }) => {
  const compact = useSyncExternalStore(subscribeCompact, isCompact);
  return (
    <DsStepper value={state.stage} onValueChange={(v) => onSelect(v as Stage)}>
      <StepperList compact={compact}>
        {STAGES.map((stage) => {
          const status = statusOf(state, stage);
          return (
            <StepperItem
              key={stage}
              value={stage}
              status={DS_STATUS[status]}
              errors={stage === "build" ? state.buildErrorCount : undefined}
              target={stage === target}
              id={`flow-stage-tab-${stage}`}
              aria-controls={`flow-stage-panel-${stage}`}
              aria-label={ariaLabelOf(state, stage, status, target)}
            >
              {LABEL[stage]}
            </StepperItem>
          );
        })}
      </StepperList>
    </DsStepper>
  );
};
```
