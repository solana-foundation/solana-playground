# 5.26 The files column keeps its state: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, the default) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hiding and showing the files column (⌘E or the stage bar's
toggle) keeps the open folders, the current file's selection, the scroll and,
in a lesson, the Steps/Files tab.

**Architecture:** The column still unmounts while hidden (design.md, "Frame
chrome (5.25)", "Hidden, not folded"). What it holds is remembered at unmount
and put back at mount: the open folders by path in the explorer's tree
(`Folders` via `useHandleItemState`), the scroll and the tab in `LeftPanel`.
Both memories are module-level, last for the page, and are keyed by
`PgExplorer.currentWorkspaceId`, read when the column hides: a memory taken on
another project is ignored, and with no project open nothing is kept. The selection already comes
back through `useHandleItemState`'s `onDidOpenFile` subscription, which fires
with the current file on subscribe.

**Tech Stack:** React 19, styled-components, vitest + Testing Library,
Playwright.

**Spec:** `openspec/changes/ui-migration/specs/client-v2-layout/spec.md`,
Requirement "Panels fold without losing their state", scenarios "The files
column keeps its tree" and "A lesson's column keeps its tab"; design.md,
"Frame chrome (5.25)". Ticket: HOO-2124.

## Global Constraints

- `src/utils/explorer` and the layout shell are not changed.
- Ids, `aria-label`s and test ids stay: `#root-dir`, `#flow-left-tabpanel`,
  `flow-left-tab-*`, "Collapse/Expand project panel".
- No empty `catch`; tests build no shapes by spread (`client-v2/AGENTS.md`).
- e2e titles are `client-v2-layout: <scenario name>`.
- Gate: `yarn run check`, plus `yarn test-e2e e2e/client-v2-layout.e2e.spec.ts`
  and `e2e/left-panel-toggle.e2e.spec.ts` on a free slot port
  (`docs/testing.md` section 8). Never the full e2e suite locally.

## Review Focus

- A folder deleted or renamed while the column was hidden: its path is
  skipped on restore, nothing throws (Task 1 test "skips a path that is gone").
- A project switch while hidden: the other project's folders and scroll are
  not applied (Tasks 1 and 2, "another project's memory is ignored").
- A file opened from the editor tabs while hidden: its parents open and it is
  selected when the column returns, on top of the remembered folders (Task 3
  e2e asserts the selected file).
- Below 768 px the column lives in the navigation's Sheet and remounts on
  every open: the same memory applies there (no new code; noted in the PR).
- Leaving a lesson and coming back: the tab memory is per project, so a
  lesson remembers its own tab (Task 2 test).

  `wrapperRef` to `useHandleItemState`)

**Interfaces:**
- Produces, in `kept-tree.ts`:
  - `openFolderPaths(root: Element): string[]`: `data-path` of every
    `.${PgView.classNames.FOLDER}.${PgView.classNames.OPEN}` under `root`.
  - `keepTree(workspace: string | undefined, root: Element): void` and
    `keptFolders(workspace: string | undefined): string[]` (empty for another
    workspace, no workspace, or nothing kept), `forgetTree(): void` (tests).
  - `reopenFolders(paths: string[], find: (path: string) => HTMLDivElement | undefined, open: (el: HTMLDivElement) => void): void`.
- `useHandleItemState(rootRef: RefObject<HTMLDivElement | null>)`: a
  `useLayoutEffect` on `[rootRef]` reopens
  `keptFolders(PgExplorer.currentWorkspaceId)` through
  `PgExplorer.getElFromPath` / `PgExplorer.openFolder`, and in its cleanup
  calls `keepTree` with the element captured when the effect ran and the
  workspace read then. Tested in `useHandleItemState.test.tsx`.

### Task 2: The column remembers its scroll and its tab

**Files:**
- Create: `client-v2/src/views/flow/left/kept-column.ts`
- Modify: `client-v2/src/views/flow/left/LeftPanel.tsx`
- Test: `client-v2/src/views/flow/left/LeftPanel.test.tsx`

**Interfaces:**
- Produces, in `kept-column.ts`:
  `type KeptColumn = { workspace: string; tab: Tab; scrollTop: number }`
  (`Tab` moves here from `LeftPanel.tsx` and is exported),
  `keepColumn(kept: KeptColumn): void`,
  `keptColumn(workspace: string | undefined): Omit<KeptColumn, "workspace"> | null`,
  `forgetColumn(): void` (tests only).
- `LeftPanel`: the lesson state starts from `PgLesson.state`, so the first
  commit already draws the right tab; `useState<Tab>(() =>
  keptColumn(PgExplorer.currentWorkspaceId)?.tab ?? "steps")`; the tab (a
  layout effect) and the scroll (`onScroll`) are tracked in a ref object, and
  a `useLayoutEffect` on `[collapsed]` restores `scrollTop` on mount and keeps
  the tracked values on unmount, since a detached body reads 0.
  Ordering: `Folders` is a descendant, so its layout effect (Task 1) has
  reopened the folders before `LeftPanel`'s restores the scroll.

- [ ] **Step 1: failing tests** in `LeftPanel.test.tsx` (mock
  `PgExplorer.currentWorkspaceId`; in the lesson tests `PgLesson` gets a

    `#flow-left-tabpanel`, unmount, draw again -> `scrollTop` is `120`.
  - "another project's memory is ignored": keep on project "a", draw on "b"

  `beforeEach(forgetColumn)`: Testing Library unmounts the last panel after the file's own `afterEach`, and that unmount keeps it again.
