**Goal:** Below 720 px the app is the prototype's three swiped pages (menu,
work, preview) with a 60 px bar, and the code editor edits at every width.

**Architecture:** `widgets/layout-shell` keeps owning the layout. The stage
and the console are rendered once, through `createPortal` into DOM nodes the
shell owns (`shared/lib/outlet`), so the four-column frame and a new
`BasePhonePager` only place those nodes, and crossing 720 never remounts
`Primary` (Monaco) or xterm. `LayoutShell` holds the phone's page and
Chat | Code view for the visit, maps them to `PgFlow.stage`, and writes
nothing to the saved layout. The read-only editor of 5.1 is deleted whole.

**Tech Stack:** React 19 (`createPortal`), CSS scroll-snap through Tailwind
4 utilities, the installed `segmented`, `sheet` and `button`, `lucide-react`,
vitest + Testing Library, Playwright.

**Spec:** `openspec/changes/ui-migration/design.md`, "The phone (5.7)" (and
"The four-column frame (5.2)" for what stays); `specs/client-v2-layout/spec.md`,
"A phone is three pages", "Four columns and no header", "The layout is
measured".

## Global Constraints

- The phone threshold is `LAYOUT_BREAKPOINTS.phone = 720`, read everywhere
  through that constant; no literal `720` (or `719`) outside
  `use-viewport.ts` and its test.
- 720–767 px keeps 5.2's layout: nav + files in the stock Sidebar's Sheet,
  the assistant in the right Sheet. `use-mobile` is not edited.
- The phone writes nothing to the `layout` localStorage key.
- A load on a phone lands on the work page, showing Code.
- Each phone page has a 60 px bar: `h-phone-bar`.
- Every existing id, `aria-label` and test id survives. New controls are named
  "Menu", "Preview the build", "Back to the code", "Files, <file> open", and
  the group "Show" with "Chat" and "Code".
- `shared/ui` is never edited by hand; install with `yarn ds-add` if a part
  is missing (none is expected: `segmented`, `sheet`, `button` are in).
- No empty `catch`; failures log through `createLogger(...)` with
  `report: true`.
- Tests: no spread to build a new fixture shape (`client-v2/AGENTS.md`).
- No nested ternaries; state shaped as types.
- Commit messages: Conventional Commits with `(client-v2)` scope, no AI
  attribution.

## Review Focus

1. **A rotation while the editor has unsaved typing**: crossing 720 both
   ways keeps the buffer and the open tab (Task 4's remount test, Task 7's
   e2e "Turning a phone across 720 px").
2. **A stage set from outside the pager** (Ctrl+2, a deploy, the StageBar's
   Write tab in Preview) must never leave the visible page without its stage
   (Task 3's `pageForStage` tests, Task 6's integration test).
3. **A swipe that ends between pages, or a resize while on Preview**: the
   pager snaps and re-aligns to its page rather than showing half of two
   (Task 5's resize test).
4. **"Fix with assistant" on a phone while on Preview or Menu** lands on Work
   showing Chat (Task 6).
5. **A deploy's auto-open of the console on a phone** opens the phone's
   console and writes nothing to `layout` (Task 6).

```tsx
import { useLayoutEffect, useRef, useState } from "react";
import type { ReactNode } from "react";
import { createPortal } from "react-dom";

/**
 * A DOM node that outlives the places it is shown in. Content portaled into
 * it keeps its React state and its DOM (an editor, a terminal) while the
 * layout around it changes, because only the node moves.
 */
export const useOutletNode = (className: string) => {
  const [node] = useState(() => {
    const div = document.createElement("div");
    div.className = className;
    return div;
  });
  return node;
};

/** The content, rendered into `node` from one place that never unmounts */
export const OutletContent = ({
  node,
  children,
}: {
  node: HTMLDivElement;
  children: ReactNode;
}) => createPortal(children, node);

/** Where `node` shows now; the last `Outlet` mounted for a node holds it */
export const Outlet = ({
  node,
  className,
}: {
  node: HTMLDivElement;
  className?: string;
}) => {
  const ref = useRef<HTMLDivElement>(null);
  useLayoutEffect(() => {
    const host = ref.current!;
    host.appendChild(node);
    return () => {
      // Another Outlet may already have taken it in the same commit
      if (node.parentNode === host) host.removeChild(node);
    };
  }, [node]);
  return <div ref={ref} className={className} />;
};
```

```ts
import type { Stage } from "@/views/flow/state/stage";

export type PhonePage = "menu" | "work" | "preview";
export const PHONE_PAGES: readonly PhonePage[] = ["menu", "work", "preview"];
export type WorkView = "chat" | "code";
export type PageSource = "swipe" | "button" | "auto";
export type PreviewStage = Exclude<Stage, "write">;

/**
 * The stage is one: Code shows it at `write`, the preview at any other. A
 * stage set from elsewhere (a key, a deploy, the stepper's Write tab) moves
 * the pager to the page that shows it, so no page is left without its stage.
 * The menu shows no stage, so `write` leaves it where it is.
 */
export const pageForStage = (stage: Stage, page: PhonePage): PhonePage | null => {
  if (stage === "write") return page === "preview" ? "work" : null;
  return page === "preview" ? null : "preview";
};

/** The stage a page sets when it comes into view */
export const stageForPage = (
  page: PhonePage,
  stage: Stage,
  lastPreview: PreviewStage
): Stage | null => {
  if (page === "work") return stage === "write" ? null : "write";
  if (page === "preview") return stage === "write" ? lastPreview : null;
  return null;
};
```

  const index = PHONE_PAGES.indexOf(props.page);

  }, [index]);
